# 두드림모터스 공식 홈페이지

두드림모터스 전체 판매 차량을 자동으로 불러와 사진·가격·연식·주행거리·연료·상세 정보를 보여주는 정적 홈페이지입니다. 방문 중에는 30분마다 최신 매물을 다시 확인하며, 외부 연결이 지연되면 `data/cars.json`의 최근 저장 데이터를 표시합니다.

## 주요 기능

- 두드림모터스 전체 실매물 검색 및 필터
- 차량별 상세 사진, 기본 정보, 성능점검 링크
- 이성신 중고차 전문가 소개와 전화·문자 상담
- 고객 매입·판매 후기 및 사진 등록
- 관리자 후기 검수, 수정, 공개/비공개, 삭제

## 전체 매물 백업 갱신

```powershell
node scripts/sync-moldeon.mjs
```

실시간 조회가 일시적으로 지연될 때 사용할 전체 매물 백업 파일 `data/cars.json`을 갱신합니다.

## 후기 게시판 설정

후기 저장과 관리자 기능은 Firebase의 Authentication, Firestore, Storage를 사용합니다. 실제 운영을 위해서는 [FIREBASE_SETUP.md](FIREBASE_SETUP.md)의 순서대로 프로젝트 정보와 관리자 이메일을 설정해야 합니다.

## 로컬 확인

```powershell
python -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다.

## 운영 확인 사항

- 홈페이지에 표시되는 상호, 주소, 사업자번호, 연락처가 실제 사업자 정보와 일치해야 합니다.
- 차량 정보 제공처의 연동 및 재게시 권한과 이용 조건을 확인한 뒤 운영하세요.
- 고객 후기 사진에는 개인정보가 포함될 수 있으므로 관리자가 공개 전 반드시 검수하세요.
